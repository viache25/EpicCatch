# Epic Catch

Реалистичная 3D-рыбалка для телефона: утреннее озеро, поплавочная удочка, заброс, поклёвка, подсечка и вываживание.

Three.js + TypeScript + Vite. Вся графика и звук генерируются в коде, внешних ассетов нет.

```bash
npm install
npm run dev      # локальный сервер, открывается и с телефона в той же сети
npm run build    # сборка в dist/
```
